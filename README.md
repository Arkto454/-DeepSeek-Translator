# 知译 · DeepSeek Translator

一个接入 DeepSeek 的轻量 Edge 浏览器翻译插件。打开网页后，点击翻译，对当前屏幕内可见的正文和界面文字生成译文，并通过悬浮球控制阅读。

**当前版本：0.1.3 · 基础翻译 MVP**

当前目标是把「配置 Key → 翻译网页 → 双语阅读 → 恢复原文」做成可用的完整流程。个人术语、译文缓存、用量统计、译文纠正和自主学习留待后续版本。

## 使用方法

### 1. 准备扩展文件和 API Key

使用前需要：

- Microsoft Edge 桌面浏览器。
- 已下载或克隆的本项目源码。
- 自己的 DeepSeek API Key，以及可用的 API 账户余额。

**只是使用插件时，不需要安装 Node.js，不需要执行 npm 命令，也不需要启动本地服务。** 后面的「开发验证」仅供需要运行测试的开发者使用。

获取项目文件可以采用任一方式：

- **下载 ZIP**：在本仓库页面点击「Code → Download ZIP」，下载后先解压。
- **使用 Git**：克隆本仓库，然后打开克隆得到的项目文件夹。

无论文件夹名称是什么，都以其中能直接看到 `manifest.json`、`background.js`、`dashboard.html` 为准。不要选择 ZIP 压缩包，也不要选择项目外层、尚未包含这些文件的目录。

建议先把解压后的项目放到准备长期保留的位置。Edge 会从该文件夹加载扩展，安装后移动或删除文件夹会导致扩展无法正常使用。

API Key 可在 [DeepSeek 开放平台](https://platform.deepseek.com/)创建。插件需要的是 API Key，不是 DeepSeek 网页聊天的登录密码。将 Key 留在本机使用，不要填入源码或上传到仓库。

### 2. 在 Edge 中安装

1. 打开 Edge，在地址栏输入 `edge://extensions/` 并回车。
2. 在扩展管理页面开启「开发人员模式」。
3. 点击「加载解压缩的扩展」。
4. 选择上一步找到的、直接包含 `manifest.json` 的项目目录。
5. 确认页面出现「知译 · DeepSeek Translator」扩展卡片，并且扩展处于启用状态。
6. 打开地址栏旁的扩展菜单，找到「知译」。可将它显示或固定到工具栏，方便之后点击；具体名称可能随 Edge 版本变化。

安装方式可参考 [Microsoft Edge 官方侧载说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。当前使用的是加载源码目录的方式，无需将扩展打包成 `.crx`。

**安装成功的标志**：点击「知译」图标，可以看到包含「翻译当前页面」和「打开 Dashboard」的快捷弹窗。

### 3. 在 Dashboard 保存模型配置

1. 点击工具栏或扩展菜单中的「知译」。
2. 点击「打开 Dashboard」，浏览器会打开独立的管理标签页。
3. 找到「连接你的翻译引擎」，填写以下配置：

| 配置项 | 如何填写 |
| --- | --- |
| DeepSeek API Key | 粘贴自己的 API Key，注意不要带入多余字符；默认隐藏，可点击「显示」核对 |
| 模型名称 | 首次使用可保留项目默认值 `deepseek-flash`；如需更换，请使用账户支持的模型名称 |
| 目标语言 | 选择希望得到的译文语言，例如「简体中文」 |

4. 点击「保存并测试连接」。此操作会先保存当前表单，再发送一个简短的翻译请求。
5. 等待状态显示「连接测试通过」。如果失败，页面会给出 Key、余额、网络、模型或服务异常等提示，按提示修正后重新测试。

「保存配置」只保存设置，不验证连接是否可用；状态显示「配置已保存」不等于连接测试已经通过。修改表单后，请再次点击保存，文本试译和网页翻译使用的是已保存的设置。

连接测试和真实翻译都会产生 API 用量。模型可用性和账户状态以 [DeepSeek 官方文档](https://api-docs.deepseek.com/)及开放平台为准；当前插件固定连接 DeepSeek 官方接口，无需填写 Base URL。

### 4. 先完成一次文本试译

建议先在 Dashboard 检查短文本，再尝试翻译整篇网页：

1. 进入「翻译工作台」。
2. 保留内置示例，或在左侧「原文」输入一小段英文。单次最多 5,000 字符。
3. 点击「开始翻译」。
4. 等待状态从「翻译中…」变为「翻译完成」，右侧「译文」应显示所选目标语言的结果。

可以用下面的句子进行首次测试：

```text
A reliable agent needs clear context and a well-defined tool contract.
```

具体译法由模型决定。当前右侧结果为只读，不提供纠正保存；再次点击「开始翻译」会重新请求 API。

如果短文本也翻译失败，先解决连接或配置问题，再进行网页翻译。

### 5. 翻译当前网页

1. 新建或切换到一个普通英文网页，例如技术文档、博客文章或 GitHub README。
2. 确保当前激活的标签页是要翻译的文章，而不是 Dashboard、扩展管理页或 PDF 阅读器。
3. 点击「知译」图标，再点击「翻译当前页面」。
4. 快捷弹窗会关闭，网页右下角应出现「译」悬浮球及「知译 · 可见内容翻译」面板。
5. 等待当前屏幕内的文字译文逐段出现。向下滚动时，新进入屏幕的正文才会请求翻译；展开折叠内容后，也只处理实际可见的部分。

默认保留原文，译文以左侧细线区分。控制条显示当前任务已翻译的文字片段数；文章较长时，可以先阅读已完成的部分。动态新增或发生文字变化的正文也会重新检查，只有进入可见区域后才会翻译。

如果没有出现控制条，请先刷新文章，再重新点击插件。若提示页面不允许运行，请换一个普通 HTTP / HTTPS 网页，参见下方「限制与排查」。

### 6. 使用阅读控制条

| 按钮或状态 | 使用方式与实际行为 |
| --- | --- |
| 暂停 | 暂停后续段落处理；当前已经发送的请求仍可能完成并显示译文 |
| 继续 | 从剩余段落继续；因错误暂停时，先修正问题，再点击继续 |
| 仅译文 | 隐藏已翻译段落的原文，方便阅读译文 |
| 双语对照 | 重新显示已翻译段落的原文 |
| 恢复原文 | 移除本次插入的译文和控制条，停止继续处理该页面 |
| 右上角 × | 收起面板，保留悬浮球；翻译任务仍会继续，不等于暂停 |
| 「译」悬浮球 | 点击展开 / 收起面板；按住拖动可调整位置；位置只在当前页面会话中保留 |
| 等待可见内容 | 当前可见文字已处理，滚动、展开或出现新内容后继续检查 |

收起面板后，可点击悬浮球再次展开；也可以点击插件中的「翻译当前页面」重新展开。悬浮球是在点击插件后注入当前页的，不会自动出现在所有网站。此时不会把已经完成的段落全部重新翻译。

如果希望停止本次翻译并回到原页面，请使用「恢复原文」；它会同时移除译文、面板和悬浮球。已发送的 API 请求仍可能完成并产生用量，但恢复后不会继续把结果插入页面。

### 7. 更改目标语言或模型

为避免同一篇文章混用不同配置，建议按以下顺序操作：

1. 在文章页面点击「恢复原文」。
2. 打开 Dashboard，修改目标语言、模型名称或 API Key。
3. 点击「保存配置」或「保存并测试连接」。更换 Key 或模型后，建议测试连接。
4. 回到文章，重新点击「翻译当前页面」。

已经显示的译文不会因为设置改变而自动更新。当前版本没有译文缓存，恢复原文后重新翻译会再次请求 API。

### 8. 更新、关闭或移除扩展

**更新源码后**：

1. 将项目文件更新到新版本，并尽量保留原加载目录。
2. 打开 `edge://extensions/`，找到「知译」卡片。
3. 点击「重新加载」或刷新图标。
4. 刷新已打开的文章页面，再点击插件开始翻译；已打开的 Dashboard 也应刷新。

通常无需卸载再安装。若重新加载后遇到连接中断，先刷新相关标签页再试。

**临时关闭**：先在已翻译页面恢复原文，再到扩展管理页关闭「知译」的启用开关；重新启用后刷新网页再使用。

**移除扩展**：在扩展管理页点击「移除」。卸载会删除本地保存的连接配置，重新安装后需要重新填写 API Key。

### 首次使用的最短检查顺序

> 加载扩展 → 打开 Dashboard → 保存并测试连接 → 完成一次文本试译 → 切到英文文章 → 翻译当前页面 → 检查双语显示 → 恢复原文。

先跑通这一流程，再尝试长文章和动态页面，便于定位问题发生在连接、文本翻译还是网页处理环节。

## 第一版包含什么

- DeepSeek API Key、模型名称和目标语言配置，支持连接测试。
- 当前屏幕内可见正文、标题和列表的逐段双语翻译；导航、按钮、链接及表单说明采用原位文字替换。
- 保留原文、链接和富文本结构，保留代码块和用户输入值，空输入框的提示文字可翻译。
- 只处理可见内容；屏幕外段落、隐藏文字、未展开内容不会提前发送。
- 翻译可见的导航、菜单、按钮、表单说明和空输入框提示文字，不改写用户输入内容。
- 原生下拉框只翻译当前显示的选中项；切换后处理新选中项，不读取整张选项表。选项提交值保持不变。
- 可点击和拖动的悬浮球，支持展开与收起阅读面板。
- 独立 Dashboard 和工具栏快捷弹窗。
- 加载状态、常见 API 错误提示、25 秒超时和连续错误暂停。

目标语言可选简体中文、繁体中文、英语和日语。请求串行处理，发送前会再次确认段落仍在当前可见区域。翻译以段落为单位，不逐行截断：段落的一部分出现在屏幕内时，可能翻译该段完整的可见正文文本，但其中隐藏的子节点不会纳入。不会预加载尚未进入屏幕的其他段落。

如果请求发送后才滚动离开，该请求可能仍会产生用量；响应返回时若段落已不可见，不会在屏幕外插入译文，之后再次进入屏幕时可能重新请求。正文采用双语插入；紧凑界面控件只替换已有文本节点或显示标签，不向控件内追加译文容器。「仅译文 / 双语对照」只控制正文显示，界面文字在点击「恢复原文」时一起还原。用户输入的值、文本编辑区和代码不会被翻译。

**每次翻译都会请求 DeepSeek。** 刷新页面、恢复原文后再次翻译，或在 Dashboard 重复试译，都会产生新的请求。当前不保存译文历史、不读取旧缓存、不进行个性化学习。

## 数据与权限

- 当前版本只持久化 API Key、模型名称和目标语言。
- API Key 保存在本机扩展存储，不是加密保险箱。存储访问限制为受信任的扩展上下文。
- 翻译请求只发送到 `https://api.deepseek.com/chat/completions`，正文与固定翻译提示一起提交；Key 作为认证信息发送。
- 网页标题、域名、前文片段不再作为额外上下文提交。页面标题本身若被识别为待翻译正文，仍会被翻译。
- 没有账号、遥测、行为采集或云端同步。请自行选择适合提交给第三方模型的文本。

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 点击扩展后访问当前标签页 |
| `scripting` | 注入页面翻译脚本 |
| `storage` | 保存模型连接配置 |
| `https://api.deepseek.com/*` | 从后台请求 DeepSeek API |

如果使用过此前版本，本机扩展存储中可能仍有旧术语、缓存与统计；当前版本不读取或更新这些数据，也不会主动删除它们。全新安装没有这些旧数据。卸载扩展会删除其本地存储。

## 限制与排查

| 现象 | 说明或处理方法 |
| --- | --- |
| Edge 内部页或扩展商店无法翻译 | 浏览器限制，请使用普通 HTTP / HTTPS 网页 |
| PDF、图片或字幕未翻译 | 暂不支持 PDF、OCR、字幕、iframe 与 Shadow DOM 内的内容 |
| 有些正文被跳过 | 先滚动到该段或展开内容；包含控件或 flex/grid 的布局不会整块插入译文，改为单独处理可见文字；正文块超过 4,500 字符等情况仍会跳过 |
| Dashboard 文本过长 | 单次试译最多 5,000 字符 |
| Key 无效或余额不足 | 检查 Dashboard 配置与 DeepSeek 账户 |
| 请求超时或服务繁忙 | 检查网络与模型名称，稍后点击继续重试 |
| 更新扩展后连接异常 | 重新加载扩展，再刷新网页 |
| 恢复原文后仍有 API 用量 | 已发送的请求可能继续完成，但不会再插入译文 |

## 开发验证

在项目根目录执行以下命令。逻辑与后台消息测试仅需 Node.js（已使用 Node.js 24 验证），无需 npm 依赖：

```powershell
npm test
```

浏览器检查额外需要 Playwright 和已安装的 Microsoft Edge。以下命令默认自动定位本机 Edge，无需填写个人安装路径：

```powershell
npm install --no-save --package-lock=false playwright
node tests/browser-smoke.mjs
```

非标准安装环境可通过 `BROWSER_EXECUTABLE` 指定浏览器可执行文件，通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径；也可使用 `BROWSER_CHANNEL` 选择已安装的浏览器渠道。未设置这些变量时，脚本使用项目可解析的 `playwright` 模块和 `msedge` 渠道，不依赖特定用户目录。

测试使用临时隔离浏览器配置和模拟 API，不使用真实 Key，不产生付费翻译请求。截图写入 `artifacts/`。当前验证范围见 [VALIDATION.md](VALIDATION.md)；真实连接与翻译效果仍需填入自己的 Key 后确认。

## 项目结构

```text
deepseek-translator/
├── manifest.json             扩展入口与权限
├── background.js             配置保存、翻译请求与消息校验
├── core.js                   默认配置、翻译提示与输出校验
├── content.js                正文扫描、译文展示与原文恢复
├── popup.html / popup.js     工具栏快捷入口
├── dashboard.html           Dashboard 页面
├── dashboard.js             连接配置与文本试译
├── ui.css                   界面样式
├── tests/                   逻辑与浏览器测试
├── artifacts/               验证截图与日志
├── VALIDATION.md            验证记录
└── README.md
```

数据流：弹窗注入内容脚本 → 内容脚本提交待译正文 → 后台读取配置并请求 DeepSeek → 页面插入译文。Dashboard 试译通过同一后台翻译接口完成。
